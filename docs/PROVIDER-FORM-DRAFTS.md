# 供应商表单草稿保护

本轮改进普通供应商的新增与编辑表单，减少后台配置读取、页签切换和误返回导致的重复填写。当前为开发源码，公开 `.9` 包保持原样；新包验收结果见本文末尾。

## 使用方式

- 编辑供应商时先读取当前配置。等待期间可选择 **使用已保存配置继续**；之后迟到的实时配置不会覆盖输入。读取失败自动使用该次打开时的已保存配置。
- 在新增窗口中，普通供应商与共享渠道页签来回切换会保留普通表单的草稿。
- 修改后点击返回、取消、按 Escape 或从编辑页进入共享渠道管理，会提示 **继续编辑 / 放弃修改**。继续编辑保留内容；放弃后关闭或跳转，再次打开使用新配置。
- 真正保存时暂时禁止离开和继续编辑。保存失败保留表单，显示固定提示，可修正或重试；成功后关闭当前表单。
- 仅搜索预设、筛选模型、展开区域或显示密钥不会标记为修改。显式修改后即使手动改回原值，本次窗口仍保留离开确认，避免遗漏高级选项。

## 边界与隐私

草稿仅存在于当前打开的表单内存，不新增磁盘文件、localStorage、历史记录或导出。不保存副本用于崩溃恢复；退出应用、强制关闭、刷新页面、程序化更换应用/编辑对象后不承诺恢复草稿。关闭窗口后相关表单会卸载，下一次打开重新初始化。

同一编辑窗口内的后台列表刷新不会重新初始化用户输入；关闭重开后读取最新配置。Codex 已保存或手工编辑的模型映射不会被后台模型目录替换；只有空且未编辑的目录可自动填充一次，后续刷新继续用于浏览。初始化按应用和供应商隔离，不会把上一条实时配置带入下一条。保留既有代理接管、共享渠道、Codex 鉴权及模型目录处理规则，不增加读取个人会话或额外密钥的路径。

本功能不实现多窗口冲突合并或跨进程版本检查。共享渠道新增/关联专用窗口保留原有行为，本轮的离开确认用于普通供应商表单及从其跳转管理共享渠道。独立保存的通用配置与端点管理仍遵循各自原有保存机制，放弃普通草稿不撤销已单独保存的操作。

## 验证进度

合成复现确认了迟到实时配置覆盖输入、相同 ID 刷新重置模型、切换对象沿用旧实时配置和页签卸载丢稿。新增回归覆盖加载失败/手动继续、迟到响应、同 ID 刷新、换应用/对象、重开、继续/放弃、保存失败/重试及旧会话完成不关闭新会话。

独立审查发现并修复自动 CodeMirror 同步和预设搜索误标修改、模型目录回调变化误回传、模型读取被误当成保存而阻止退出。类型检查、格式、严格 Clippy、renderer 构建及 72 项定向测试已通过。本机全量前端 1165 项通过，App 初始化和 Pi 用例各出现一次超时；两文件与新增目录回归定向复测共 64 项通过（仅命令行将初始化等待设为 60 秒，仓库默认超时未修改）。干净 CI 默认全量与真实 Windows 新包结果仍待完成，不能用源码测试代替安装包验收。

验收仅使用虚构密钥、合成配置、回环地址和 runner 内模拟 IPC 失败；不在个人环境启动应用、不读取个人客户端密钥和会话、不调用付费 API。
