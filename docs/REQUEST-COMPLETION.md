# 请求结果与成功率

本功能已随 [Windows x64 `.9`](releases/3.20.1-yunswitch.9.md) 公开。下方保留功能开发阶段的 build-only 验收记录；公开 `.8` 原附件不变。

当前开发源码把请求的最终结果统一用于 **设置 → 路由 → 请求诊断**和本地路由总览。收到 HTTP 200 或响应头不再立即增加成功数；部分输出后失败、超时或取消会得到相应结果。

总览显示成功、失败、超时、取消、结果未确认和进行中。成功率为 `成功 ÷（成功 + 失败 + 超时）`；没有可确认结果时显示“暂无结果”。进行中、取消及未确认不进入分母。总数覆盖进入被跟踪处理器的请求，包含请求解析、鉴权和无可用供应商失败；同一请求重试或切换备用仍只计一次。

## 判定规则

| 客户端响应                                | 完成判定                                                                                                                    |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Responses                                 | `response.completed` / `status: completed` 为成功；failed、incomplete、cancelled 分别记失败、未完成或取消。                 |
| Messages                                  | 使用 `message_stop` 和 stop_reason；max_tokens、上下文上限归未完成，不计成功。                                              |
| Chat Completions                          | 所有请求的或已观察到的 choice 都有可识别 finish_reason 后完成；length 归未完成。正常 finish_reason 后缺少 `[DONE]` 仍兼容。 |
| Gemini 原生生成                           | 按 candidateCount 和候选索引等待全部结果；MAX_TOKENS 等截断不计成功。明确拒绝是协议已完成，不表示生成了用户期望的内容。     |
| compact、Alpha Search、非生成 Gemini 端点 | 按 HTTP 响应交付完成；不套用生成协议终态。                                                                                  |

已知 SSE 正常结束但没有完成信号时记“响应未完成”。明确终态在交给客户端前结算一次，因此客户端紧接着关闭不会再改成取消。首个有效终态确定后，重复或尾部事件不重复结算；这是代理观察口径，不证明客户端已保存或执行输出。

非流 JSON 的 HTTP 200 也会检查协议状态。未知格式、损坏数据、未解码压缩内容或超出观察范围且没有后续可确认终态时，显示“结果未确认”及原因，不把未知当成功。原生响应字节保持原样交付。

## 资源与兼容边界

单个 SSE 观察事件和非流 JSON 观察体各最多 256 KiB，候选索引最多 32 个；超限请求继续转发。只保留有限临时缓冲与计数，不保存输出、工具参数或上游错误原文到诊断。摘要仍沿用[脱敏字段与保留期限](REQUEST-DIAGNOSTICS.md)。

最终统计独立于诊断最多 128 条活跃记录的容量，超出后仍计数。取消和停止会回收进行中数量；停止前的迟到收尾不会影响重启后的请求。通过桌面服务重新启动代理会创建新运行统计。健康检查和本地模型目录不计入请求生成统计；现有 Gemini 代理的非生成端点沿用其被跟踪处理器范围。

Gemini 转 Messages 遇到缺失、未知或异常完成原因时返回固定安全错误。MAX_TOKENS 保留文本和用量的截断终态，未完成工具参数不变为工具调用，截断内容不进入 shadow 回放历史。其他转换路径继续沿用既有协议映射，由客户端实际收到的协议终态判定结果。

供应商健康、恢复许可、共享冷却、备用选择及切换时机不因统计改变。重试仍有次数和时间上限；已有文本、推理或工具活动后不重放，状态型 Codex 保持一次发送保护，加密历史兼容默认关闭。用量计费日志和请求结果统计用途不同，本轮未统一历史用量记录的 HTTP 状态字段。
